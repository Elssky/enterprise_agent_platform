## 本版编辑原则

优化过程中遵循以下原则：保留核心定义、工程判断、重要案例、图片、表格和参考文献；合并过细小节；删除同义反复和低信息量扩写；根据内容密度将章节整体压缩约 30%–50%；并用少量 **加粗结论句** 提升扫读效率。
